Deployment

Deployment-ready with railway.toml, Dockerfile, and Procfile.

Required env vars:

  • DATABASE_URL — PostgreSQL connection string
  • SECRET_KEY — JWT signing key
  • ADMIN_EMAIL / ADMIN_PASSWORD — Master user credentials
  • ACCESS_TOKEN_EXPIRE_MINUTES — Token expiry (default 1440 = 24h)
